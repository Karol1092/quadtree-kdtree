# Drzewa czwórkowe (Quadtrees) oraz k-d drzewa

Implementacja drzew czwórkowych (quadtrees) oraz k-d drzew na rzecz projektu z kursu Algorytmów Geometrycznych na Wydziale Informatki na Akademia Górniczo-Hutnicza im. Stanisława Staszica w Krakowie.

## Cel
Drzewa czwórkowe i k-d drzewa są strukturami danych używanymi do przechowywania informacji przestrzennych. Drzewa czwórkowe dzielą przestrzeń na cztery części, podczas gdy k-d drzewa dzielą przestrzeń na k wymiarów.

- Python 3.12
